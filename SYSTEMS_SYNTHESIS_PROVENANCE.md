## Evidence rule

The portfolio separates four questions:

1. **Did Cory perform the historical activity?** — professional records and firsthand corroboration can help establish this.
2. **When did a computational mechanism become publicly inspectable?** — Git history, source artifacts, hashes and deposits answer this.
3. **Did Cory author the particular implementation/expression?** — file/commit-level provenance and ancestry analysis answer this.
4. **Was Cory first in the world to an underlying technical idea?** — this requires a separate global prior-art review and is not inferred merely from an early Git timestamp.

**The goal is not to turn every similarity into an ownership claim. The goal is to preserve an auditable map of what was built, when it appeared, how it evolved, and where the evidence ends.**
