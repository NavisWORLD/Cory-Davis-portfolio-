## Evidence language

The portfolio uses six labels:

- **IMPLEMENTED** — inspectable code or artifact exists.
- **OBSERVED** — captured runtime evidence shows a mechanism executed.
- **MEASURED** — a declared benchmark produced a metric.
- **NULL** — the declared success condition was not supported.
- **HYPOTHESIS** — falsifiable interpretation awaiting evidence.
- **METAPHOR / MODEL** — design language, not a literal physical or biological claim.

The purpose of this index is not to flatten every repository into one claim. It is to make the lineage navigable while preserving attribution, failures, corrections, and privacy boundaries.
