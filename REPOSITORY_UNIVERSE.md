## Provenance rules used by this index

- **Repository creation date is not mechanism priority.** A mechanism is dated to the first located commit where the mechanism can actually be inspected.
- **File presence is not authorship.** Mixed-lineage repositories require file/commit-level attribution.
- **Imported history is not Cory priority.** Third-party commits keep their actual author/upstream provenance.
- **A filename cannot backdate a feature.** Labels such as `Q1 2025` are not treated as timestamps when Git history says otherwise.
- **Later productization does not backdate 2025 research.** August 2026 libraries/apps are 2026 engineering surfaces unless an independent earlier receipt exists.

## Evidence language

The portfolio uses six labels:

- **IMPLEMENTED** - inspectable code or artifact exists.
- **OBSERVED** - captured runtime evidence shows a mechanism executed.
- **MEASURED** - a declared benchmark produced a metric.
- **NULL** - the declared success condition was not supported.
- **HYPOTHESIS** - falsifiable interpretation awaiting evidence.
- **METAPHOR / MODEL** - design language, not a literal physical or biological claim.

The purpose of this index is not to flatten every repository into one claim. It is to make the lineage navigable while preserving attribution, failures, corrections, mixed ancestry and privacy boundaries.
