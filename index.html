Evidence standard

The vocabulary is ambitious. The labels are strict.

A system can be interesting without being proven. My public work uses a claim taxonomy so code, runtime evidence, measurements, nulls, hypotheses, and metaphors do not get collapsed into one story.

  • IMPLEMENTEDInspectable code or artifact exists.
  • OBSERVEDCaptured runtime evidence shows execution or state.
  • MEASUREDA declared benchmark produced a metric.
  • NULLThe success condition was not supported.
  • HYPOTHESISA falsifiable interpretation awaiting evidence.
