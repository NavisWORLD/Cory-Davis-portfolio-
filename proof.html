Proof OS // identity ≠ truth ≠ authorship

Hash the artifact. Version the implementation. Test the claim.

The portfolio deliberately refuses to use one kind of evidence as a substitute for another. SHA-256 proves bytes. Git records versions. Drive records public source files. A DOI records a deposit. Benchmarks and controls evaluate technical claims.

Four different questions

Use the right proof for the right claim.

A strong technical record becomes weaker when every screenshot, hash, DOI, metric, and metaphor is presented as the same category of proof.

SHA-256Artifact identity

Are these the exact same bytes?

Cryptographic digests identify source files and detect modification. They do not prove scientific truth or authorship by themselves.

GitVersion history

What source state existed publicly?

Commits, trees, and repository timestamps provide a public code/document lineage. Mixed/upstream code still keeps its own attribution.

DOI / DrivePublic record

The CST line includes Zenodo DOI 10.5281/zenodo.17574447. The August 12 portfolio library also has public Drive file IDs and exact source-byte fingerprints.

Tests / controlsScientific evidence

Did the mechanism satisfy its declared criterion?

Frozen data, seeded controls, preflight diagnostics, baselines, measurements, and preserved nulls determine the narrow technical claim.

Claims with boundaries

The nulls stay visible.

This is where the portfolio gets useful: positive mechanisms are bounded to the tested scope, and negative results are not edited out.

Measured / boundeddyn12

Compact dynamic state

In the documented frozen-corpus state ladder, dyn12 produced the strongest mean validation loss among the tested mechanism rungs and improved over the no-state baseline across the three reported seeds.

Boundary: this is not a claim that twelve channels are universally optimal.

NULLQuantum advantage

Provenance is not performance.

Measurement-derived quantum provenance can be auditable. The current matched public tests do not establish a general accuracy advantage from quantum randomness.

NULLPaired state

Aligned state did not beat plain attention.

The documented 2026-07-30 measured-state benchmark preserved its preregistered NULL despite aligned state beating some destroyed-pairing conditioned controls.

Prototype specificationHEHS

Measure the hardware before promising power.

HEHS v2 is a measurement-first build and validation plan. A specific physical build needs raw source/load measurements before a source-specific performance claim.

Privacy is part of provenance

You do not prove engineering by publishing someone's private life.

Private logs, family records, credentials, raw conversations, raw camera/audio/biosignal data, travel documents, and personal interpretive files stay outside the public proof layer.
