# 05 // PROOF MODEL

```text
SHA-256          -> exact file identity
Git history      -> version / authorship / mechanism chronology
DOI              -> deposited/citable record
runtime/test log -> mechanism executed under captured conditions
controlled bench -> performance on declared code/data/seeds/metric
replication      -> result reproduced in the replicated scope
NULL             -> declared success criterion was not supported
```

### Evidence vocabulary

- **IMPLEMENTED** - inspectable code/artifact exists.
- **OBSERVED** - captured runtime evidence shows execution/state.
- **MEASURED** - a declared benchmark produced a metric.
- **NULL** - the declared success condition was not supported.
- **HYPOTHESIS** - falsifiable proposition awaiting evidence.
- **METAPHOR / MODEL** - conceptual/design language, not literal physics/biology without separate evidence.

### Nulls intentionally preserved

- The documented paired measured-state benchmark did **not** beat plain attention under its declared success criterion.
- Matched public quantum-randomness comparisons do **not** currently establish a general ML-accuracy advantage.
- Higher-dimensional state variants did **not** monotonically outperform compact dyn12 in the documented ladder.

The goal is not to protect the theory. The goal is to make the mechanism inspectable enough to survive being wrong.
