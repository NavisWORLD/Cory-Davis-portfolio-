# Portfolio Provenance and Attribution

This repository is the public presentation layer for Cory Davis / NavisWORLD. It links to a larger body of work whose files do not all share one origin or license.

## What this repository owns

The original static portfolio site code, layout, navigation, résumé presentation, project summaries, and portfolio-specific tests in this repository are released under this repository's MIT License.

## What this repository does not automatically relicense

A link from this portfolio does **not** change the license, ownership, or attribution requirements of:

- COSMOS historical/runtime files;
- Davis CST repositories and historical artifacts;
- model weights or Hugging Face artifacts;
- third-party or upstream source code;
- datasets;
- external images, media, papers, or provider records;
- adapted or reconstructed code in other repositories.

Each linked project must be reviewed under its own license and provenance record.

## Public attribution labels

The broader Career OS / COSMOS documentation uses these distinctions:

- **CORY-AUTHORED / VERIFIED** — supported by primary source or reliable commit history.
- **ADAPTED / DERIVED** — Cory-directed or Cory-modified work with identifiable upstream ancestry.
- **UPSTREAM / THIRD PARTY** — external work retained with its own attribution/license.
- **RECONSTRUCTION / REFERENCE** — newly written teaching/rebuild code expressing a documented mechanism; not claimed as a byte-for-byte historical implementation.
- **EXPERIMENTAL** — active mechanism or prototype whose significance remains under test.
- **UNKNOWN / NEEDS AUDIT** — attribution is not yet strong enough for a confident claim.

## Rule for reviewers

**File presence is not proof of authorship.**

For mixed-lineage repositories, inspect commit history, source records, licenses, headers, upstream references, and the actual transformation history before attributing a component.

## Privacy boundary

The portfolio intentionally avoids publishing private research logs, personal conversations, raw camera/audio, raw biosignals, API keys, credentials, private family records, or other private source material merely to strengthen a technical claim.
