Evidence standard
Leave the nulls in the museum.
A result that fails is still part of the engineering lineage. The portfolio keeps explicit labels so screenshots, code, metrics, hypotheses, and metaphors do not collapse into one story.
  • IMPLEMENTEDInspectable code or artifact exists.
  • OBSERVEDCaptured runtime evidence shows execution or state.
  • MEASUREDA declared benchmark produced a metric.
  • NULLThe declared success condition was not supported.
  • HYPOTHESISA falsifiable interpretation awaiting evidence.

          
01PASS artifact exists → link it
02PASS mechanism runs → instrument it
03NULL hypothesis misses → preserve it
04HYPOTHESIS ask the next test
05rule = "claims follow instrumentation"
