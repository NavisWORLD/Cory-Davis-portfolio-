## Evidence boundary

**Hashes prove exact bytes. Git commits prove version history. Drive IDs/timestamps prove a public file record. DOI records establish a publication record. None of those, by themselves, proves a scientific hypothesis is true.**

That separation is intentional and is part of the portfolio’s engineering standard.
