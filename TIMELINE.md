# CORY DAVIS // CAREER + RESEARCH + PUBLIC ARTIFACT TIMELINE

```text
technical operations -> CST lineage -> executable public mechanisms -> autonomous systems -> productization
```

This timeline intentionally keeps separate clocks:

- **Career date** - a date stated in the source resume/work-history record.
- **Research-lineage date** - a date stated inside project manuals or archives. It records internal project history and is labeled as such.
- **Repository creation date** - when GitHub reports a repository was created.
- **Mechanism receipt date** - the earliest located platform-native commit where the actual mechanism can be inspected.
- **Later consolidation date** - when older and newer material was gathered into a later repository. This does not backdate the imported material.

A filename, README heading, current archive path, repository name, or later import is never used by itself to manufacture an earlier technical date.
